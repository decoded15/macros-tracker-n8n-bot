# AI Nutritionist — Telegram-Based Macro Tracker

An AI-powered nutrition tracking bot built using **n8n, Google Gemini, and Telegram**. It helps users log meals, estimate nutritional values, and track their daily calorie and macronutrient intake through simple Telegram commands.

## Project Overview

AI Nutritionist uses Google Gemini to understand natural-language food descriptions and estimate the nutritional information of individual food items.

The workflow processes the results, calculates nutritional totals, stores meal records in n8n Data Tables, and sends a formatted response through Telegram.

## Features

- **AI-Powered Food Analysis:** Uses Google Gemini to identify food items and estimate their nutritional values.
- **Individual Food Breakdown:** Provides calories, protein, carbohydrates, and fat for each food item.
- **Automatic Macro Calculation:** Calculates total nutritional values for each meal.
- **Daily Nutrition Tracking:** Retrieves logged meals and calculates daily totals.
- **Persistent Meal Logging:** Stores food entries in n8n Data Tables.
- **Telegram Integration:** Interact with the nutrition tracker using simple commands.

## Telegram Commands

| Command | Function |
|---|---|
| `/start` | Displays the welcome message and instructions |
| `/add` | Logs a meal and returns estimated nutrition |
| `/tracker` | Displays daily calorie and macro totals |

Example:

```text
/add 2 eggs and 2 rotis with dal
```

The bot identifies the food items, estimates their nutritional values, calculates totals, and stores individual food records.

## Data Storage

The workflow uses an n8n Data Table named `meal_log`.

Each food entry stores:

- Chat ID
- Date
- Timestamp
- Food name
- Quantity
- Calories
- Protein
- Carbohydrates
- Fat

## Setup

1. Install or access an n8n instance.
2. Import the workflow JSON from the `workflows/` directory.
3. Configure Telegram Bot API credentials.
4. Configure Google Gemini API credentials.
5. Set up the required `meal_log` Data Table.
6. Activate the workflow and test the Telegram commands.

**Note:** Credentials are not included in this repository. Users must configure their own credentials and data table.

## Important Disclaimer

Nutritional values generated by AI are estimates and may vary depending on ingredients, preparation methods, and portion sizes. They should not be treated as exact dietary measurements.
